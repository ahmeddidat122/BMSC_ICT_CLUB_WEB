# 🔧 ICT CLUB WEBSITE REDESIGN – MASTER PROMPT

## Step 1: Full Website Audit & Understanding
Carefully analyze the entire existing website before making any changes.

- Map out all pages, subpages, navigation flows, and hidden sections.
- Identify broken links, UI inconsistencies, outdated design patterns, and performance issues.
- Document all bugs, errors, and non-functional features (especially forms, buttons, and navigation).
- Evaluate usability: note confusing layouts, poor readability, or cluttered sections.
- Do NOT assume anything—verify every issue by checking actual behavior.

---

## Step 2: Define Modern Design Direction
Establish a clean, modern visual identity suitable for an ICT club.

- Use a minimal, tech-inspired design language (whitespace, clear typography, subtle animations).
- Choose a consistent color palette (primary, secondary, accent).
- Use modern UI patterns (cards, grids, responsive layouts).
- Avoid unnecessary elements like fake counters, demo statistics, or bloated sections.
- Ensure accessibility: readable fonts, proper contrast, and responsive design for all devices.

---

## Step 3: Redesign Navigation (Clean & Smart)
Rebuild the navigation system to be intuitive and clutter-free.

- Create a simple, clean top navigation bar with essential links only.
- Group related pages logically (e.g., Activities, Courses, Notices).
- Implement dropdowns only where necessary—avoid overcomplication.
- Ensure mobile responsiveness with a well-designed hamburger menu.
- Add clear navigation cues (active states, breadcrumbs if needed).
- Make sure every link works correctly—no dead ends.

---

## Step 4: Page-by-Page Redesign
Redesign each page individually while maintaining consistency.

- Improve layout hierarchy (clear headings, sections, spacing).
- Replace clutter with meaningful content blocks.
- Ensure visual consistency across all pages.
- Optimize loading performance (lightweight assets, efficient structure).
- Remove redundant or outdated content.

---

## Step 5: Subpages & Nested Content Optimization
Deeply review and improve all subpages.

- Ensure subpages follow the same design system as main pages.
- Fix broken navigation between parent and child pages.
- Improve content organization for clarity and usability.
- Remove duplication or unnecessary nesting.
- Ensure each subpage has a clear purpose and structure.

---

## Step 6: Bug Detection & Fixing (Strict Validation)
Thoroughly identify and fix all bugs without assumptions.

- Check every button, form, link, and interactive element.
- Validate forms (input validation, error handling, submission logic).
- Fix layout bugs (overflows, misalignment, responsiveness issues).
- Re-test each fix to ensure it actually works.
- Do not hallucinate fixes—verify functionality through testing logic.

---

## Step 7: Admin Dashboard Reconstruction
Completely rebuild the non-functional admin dashboard.

- Design a clean, intuitive admin interface.
- Implement core features:
  - Add/edit/delete courses  
  - Add/edit/delete notices  
  - Manage content dynamically  
- Ensure proper form handling and data flow.
- Add validation and feedback (success/error messages).
- Structure dashboard navigation clearly (sidebar or top menu).
- Ensure security basics (input validation, restricted access logic).

---

## Step 8: Functional Integration
Ensure all components of the website work together seamlessly.

- Connect frontend elements with backend/admin features logically.
- Ensure content added from the dashboard reflects correctly on the site.
- Test dynamic updates (courses, notices, etc.).
- Verify consistency across all pages after integration.

---

## Step 9: Inspiration from High-Quality Websites
Take design and UX inspiration from well-known, modern websites in similar niches.

- Focus on layout, navigation patterns, and interaction design.
- Adapt ideas appropriately—do NOT copy directly.
- Ensure the final design feels original yet professional.

---

## Step 10: Add Creative & Innovative Features
Enhance the website with useful and creative additions.

- Add interactive elements (hover effects, smooth transitions).
- Include useful resources (learning materials, event highlights, etc.).
- Keep features meaningful—avoid unnecessary complexity.
- Ensure all additions improve user experience and do not break functionality.

---

## Step 11: Performance & Responsiveness Optimization
Ensure the website is fast and works on all devices.

- Optimize images and assets.
- Ensure responsive design across mobile, tablet, and desktop.
- Minimize unnecessary scripts or heavy elements.
- Test loading speed and interaction smoothness.

---

## Step 12: Final Testing & Quality Assurance
Perform a complete final review of the entire system.

- Test every page, subpage, and feature again.
- Recheck all bug fixes.
- Ensure navigation is flawless.
- Validate admin dashboard functionality thoroughly.
- Confirm there are no broken elements, inconsistencies, or errors.

---

## Step 13: Stability & Non-Breaking Guarantee
Before finalizing:

- Ensure all new features integrate without breaking existing functionality.
- Maintain clean, maintainable code structure.
- Avoid overengineering—keep it scalable and stable.
